# venv

\## Automatización de pruebas API



Este proyecto permite realizar pruebas automatizadas de una API utilizando Python y pytest.



\### Objetivo



Verificar el funcionamiento de los endpoints mediante pruebas automatizadas, comprobando los códigos de respuesta HTTP y los datos devueltos por la API.



\### Control de versiones



El proyecto utiliza Git para registrar los cambios realizados y GitHub para almacenar y sincronizar el repositorio remoto.
